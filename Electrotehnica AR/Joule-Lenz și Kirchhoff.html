1

Legea transformării energiei în conducție (Joule-Lenz)

Trecerea curentului electric prin conductoare este întotdeauna însoțită de transformări de energie. În conductoarele omogene transformarea are un singur sens: energia electromagnetică devine căldură. Acesta este efectul Joule-Lenz, sau efectul termic al curentului.

În conductoarele neomogene (cu surse) apar și alte transformări, în ambele sensuri: din energie electromagnetică în energie chimică, luminoasă sau mecanică, ori invers.

Forma locală

p = E · J[W/m³]

E este intensitatea câmpului electric, iar J densitatea de curent. p este puterea cedată de câmp unității de volum a conductorului.

Forma integrală

Integrăm pe volumul unui conductor filiform neramificat, de secțiune S constantă și lungime l. Pe secțiune J este constant, iar E, J și dl sunt coliniari. Cu dV = S dl și J S = I:

P = ∫V E·J dV = I ∫l E·dl = Ub I

Puterea totală cedată de câmp unei porțiuni de conductor este produsul dintre tensiunea la borne și curentul care îl parcurge. Folosind legea conducției în formă integrală, Ub + e = R I, obținem:

P = UbI = RI2 − eI = PR − Pe

PR = RI2 este totdeauna pozitivă: puterea disipată ca căldură. Pe = eI este puterea generată de sursă; e pozitivă când e și I au același sens. Pentru un conductor fără surse rămâne P = RI2 = Ub2/R.

Aplicații

  • încălzirea, topirea, călirea și sudura electrică;
  • dispozitive de protecție: siguranțe fuzibile, relee termice;
  • iluminatul incandescent.

Tot efectul termic stabilește, în principal, dimensionarea secțiunii conductoarelor. În calculator, mărește curentul sau micșorează secțiunea și urmărește densitatea de curent J = I/S.

2

Topologia circuitelor de curent continuu

Un circuit (rețea electrică) este un ansamblu de surse și receptoare legate prin conductoare. Topologic, rețeaua se descrie prin trei elemente:

LaturaPorțiune neramificată, cu surse și/sau receptoare în serie. Curentul este același în orice punct al ei.
NodulPunct în care sunt conectate cel puțin trei laturi.
OchiulSuccesiune de laturi care formează un contur închis.

Se pot alege întotdeauna ochiuri fundamentale (independente): împreună cuprind toate laturile, iar niciunul nu poate fi dedus din celelalte. Numărul lor este:

O = L − N + 1L laturi · N noduri

Circuitele sunt considerate filiforme și liniare: rezistențele nu depind de curenți, iar conductoarele de legătură au rezistență nulă.

3

Teoremele lui Kirchhoff

Prima teoremă (noduri)

Rezultă din legea conservării sarcinii în regim staționar, aplicată unei suprafețe închise în jurul nodului.

∑k∈(n) Ik = 0

Suma algebrică a curenților din laturile incidente într-un nod este nulă. Convenția din curs: curenții care intră în nod cu +, cei care ies cu −.

Consecință: de-a lungul unei laturi curentul este același, derivațiile au loc doar în noduri. Ampermetrul se poate monta oriunde pe latură.

A doua teoremă (ochiuri)

Rezultă din legea conducției integrată pe conturul închis al unui ochi independent, într-un sens de parcurgere ales.

∑k∈(o) ek = ∑k∈(o) RkIk

Suma algebrică a t.e.m. din laturile unui ochi este egală cu suma algebrică a căderilor de tensiune. Termenii orientați ca sensul de parcurgere intră cu +, ceilalți cu −.

4

Calculul curenților cu teoremele lui Kirchhoff

Problema principală a teoriei circuitelor de c.c. este determinarea curenților prin laturi, când se cunosc sursele și receptoarele. Curenții dimensionează conductoarele și aparatele de protecție și comandă. Numărul de ecuații independente este egal cu numărul de curenți necunoscuți:

  1. analiza topologică: numărul de noduri N, de laturi L și de ochiuri independente O = L − N + 1;
  2. se atribuie arbitrar un sens fiecărui curent (dacă la final un curent iese negativ, sensul real este opus celui ales);
  3. se aleg arbitrar sensuri de parcurgere pentru ochiurile independente;
  4. se scrie prima teoremă pentru N − 1 noduri;
  5. se scrie a doua teoremă pentru cele O ochiuri independente;
  6. se rezolvă sistemul de (N − 1) + O = L ecuații.

Exemplul din curs (fig. 4.20)

Rețeaua are N = 4 noduri (A, B, C, D), L = 6 laturi și O = 3 ochiuri independente. Pentru nodurile A, B, C și ochiurile I, II, III rezultă:

A−I1 − I2 − I6 = 0
BI2 + I3 − I5 = 0
CI5 + I6 − I4 = 0
Ie1 − e2 = I1R1 + I3R3 − I2R2
IIe4 = I4R4 + I3R3 + I5R5
IIIe2 − e6 = I2R2 + I5R5 − I6R6

Exemplul 1 din secțiunea următoare rezolvă exact această rețea, cu valori numerice alese de noi. Pentru rețele mari se folosesc metode numerice; aici sistemul se rezolvă prin eliminare Gauss.
