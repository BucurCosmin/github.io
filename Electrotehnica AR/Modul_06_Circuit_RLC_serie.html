Circuitul RLC serie

Descoperă cum rezistența, bobina și condensatorul influențează curentul alternativ, defazajul și rezonanța.

1. Componentele în serie

O sursă sinusoidală alimentează un rezistor, o bobină și un condensator legate în serie. Același curent trece prin fiecare componentă, dar tensiunile lor nu sunt în general în fază.

Rezistorul R

Tensiunea UR este în fază cu curentul. Rezistența se măsoară în ohmi (Ω).

Bobina L

Tensiunea UL este înaintea curentului cu 90° pentru o bobină ideală. L se măsoară în henry (H).

Condensatorul C

Tensiunea UC este în urma curentului cu 90° pentru un condensator ideal. C se măsoară în farazi (F).

2. Reactanță și impedanță

Reactanța arată opoziția bobinei sau a condensatorului la curentul alternativ. La frecvența f, pulsația este ω = 2πf.

XL = 2πfL   ·   XC = 1 / (2πfC)   [Ω]

XL crește cu frecvența, iar XC scade. Reactanța totală este X = XL − XC. Impedanța complexă și modulul ei sunt:

Z = R + j(XL − XC)   ·   |Z| = √(R² + X²)

În triunghiul impedanțelor, R este cateta orizontală, X este cateta verticală cu semn, iar |Z| este ipotenuza. Dacă X este negativ, triunghiul se află sub axa orizontală.

3. Defazaj și rezonanță

φ = atan2(XL − XC, R)   ·   I = U / |Z|

Aici φ este faza tensiunii sursei față de curent. Pentru X > 0 circuitul este inductiv și curentul rămâne în urmă; pentru X < 0 este capacitiv și curentul este înaintea tensiunii.

Rezonanța serie

La f0 = 1 / (2π√LC), reactanțele sunt egale: XL = XC. Impedanța devine |Z| = R, φ = 0°, iar curentul este maxim pentru o tensiune dată. Tensiunile pe bobină și condensator se opun în fază și pot fi fiecare mai mari decât tensiunea sursei.

Puterea activă este P = UI cos φ = I²R (W), puterea reactivă este Q = I²X (var), iar puterea aparentă este S = UI (VA). Semnul lui Q indică regimul inductiv (+) sau capacitiv (−).

4. Simulator interactiv

Modifică valorile și urmărește cum se schimbă triunghiul și undele. Simulatorul folosește valori efective (RMS), componente ideale și regim sinusoidal staționar; nu modelează tranzitoriul de pornire.

5. Experimentează

  1. Apasă „Setează frecvența de rezonanță”. Observă XL, XC și defazajul.
  2. Redu frecvența sub f0. De ce devine circuitul capacitiv și ce se întâmplă cu faza curentului?
  3. Crește frecvența peste f0. Urmărește semnul lui X și poziția triunghiului.
  4. La rezonanță, modifică R. Compară curentul și tensiunile UL și UC.
